# 群像叙事 · AI 小说工坊

一个纯前端、单文件 Web 应用，通过 Anthropic Claude API 实现：
- 角色管理（新增、查看、删除、角色设定、颜色）
- 旁白与角色双轨推进（旁白、自动、指定角色）
- AI 生成对话与场景叙述，支持“导演指令”互动
- 故事记录与摘要面板、导出文本、清空重写

## 文件说明
- `小说.html`: 该项目的主入口，包含 HTML/样式/JavaScript，全功能一体文件
- `Redame.md`: 项目说明文档（当前文件），可用于 GitHub 展示

## 使用步骤
1. 直接在浏览器中打开 `小说.html`。
2. 顶部输入或粘贴 Anthropic API Key（`sk-ant-...`），会自动保存到 `localStorage`。
3. 左侧点击“+”添加角色：姓名、身份、背景、色彩。
4. 中间输入框填入指令（例如："请让他们在雨夜相遇"），按回车或点击发送。
5. 选择旁白/自动/角色对话模式：
   - 旁白推进：让 Claude 生成叙事段落
   - 自动选角：系统随机选择角色交互
   - 指定角色：让某个角色发言
6. “自动推进一回合”可快速推进剧情并让所有角色回应。
7. 从右侧“故事记录”查看摘要，点击角色查看档案。
8. 点击“导出故事”下载当前故事文本。
9. 点击“清空重来”重置状态。

## 开发与调试
- 可用本地静态站点运行，比如 `python3 -m http.server` 
- 由于浏览器同源限制，直接 `file://` 打开可能受某些浏览器策略影响，推荐 http 方式

## 关键变量与函数
- `API`, `MODEL`: Anthropic Claude API 地址与模型名称
- `renderChars()`: 更新角色列表和选项
- `addEntry()`: 渲染故事条目
- `claude()`: 调用 Anthropic API
- `narratorSys()`, `charSys(c)`: 动态生成系统提示模板
- `doSend()`, `gen()`, `doAutoAdvance()`: 核心交互逻辑

## 注意事项
- 需要有效的 Anthropic API key
- 确认网络可访问 `https://api.anthropic.com` 
- 额度消耗与 Claude 模型响应时延由你申请的 API 计划决定
